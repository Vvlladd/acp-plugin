# Distribution and license scope

The [ACP core](https://github.com/Vvlladd/acp-core) is public under MIT: Rust CLI/daemon, MCP/socket
interfaces, roles/prompts, schemas, tests and the matching Swift analyzer. This host plugin,
commands, packaging scripts and documentation are also MIT. The optional Mac app remains private
and is not included in either public repository. Provider tools/accounts have their own terms.

MIT permits use, modification and redistribution, including commercial use, while requiring
retention of its notice. Dependencies retain their own licenses and binary packages carry their
notices. See [LICENSE](../LICENSE), [runtime terms](RUNTIME-TERMS.md) and the core's license.

A marketplace installs instructions, not a Rust runtime. Most users install the compiled
CLI/helper package; contributors can [build the public source](https://github.com/Vvlladd/acp-core/blob/main/docs/INSTALLATION.md).
No paid ACP plan or Mac app is required for the local core workflow. Model usage uses the user's
provider allowance and is not included with an MIT license.

The 2026-10-11 compiled-only preview remains immutable with its original asset/checksum and terms.
New MIT distributions use a new release. Source publication does not make binaries notarized or
prove broader platform acceptance. There are no source-obscurity or exclusive-interoperability
claims. Commercial work and proposed continuity automation remain postponed.
